# PicoVISTA project page

Static, dependency-free project page for the anonymous PicoVISTA manuscript.

## Preview locally

Run any static file server in this directory, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish

The repository is compatible with GitHub Pages as-is. Keep author, institution,
paper, and code links anonymized until the double-blind review period ends.
